# Glossary (Western, Indian and producer terms)

Short definitions; the file in brackets has the full treatment.

## Western theory
| Term | Meaning |
|---|---|
| Accidental | a sharp/flat/natural outside the key signature [fundamentals] |
| Anacrusis | pickup notes before the first downbeat [rhythm] |
| Appoggiatura | an accented dissonance resolving by step [harmony §5] |
| Arpeggio | a chord played one note at a time [chords] |
| Augmented 6th | a predominant chord (It/Fr/Ger) whose b6 and #4 expand to an octave on 5 [harmony §6] |
| Avoid note | a scale tone a half step above a chord tone; clashes if held [jazz] |
| Borrowed chord / modal mixture | a chord from the parallel key [harmony §6] |
| Cadence | a phrase ending: PAC, IAC, HC, plagal, deceptive [harmony §2] |
| Chromatic mediant | a chord a 3rd away with a changed quality (C → E, C → Ab) [harmony §6] |
| Circle of fifths | keys arranged by 5ths; neighbours differ by one note [harmony] |
| Common tone | a note shared by two chords [voice-leading] |
| Counterpoint | combining independent melodic lines [voice-leading §4] |
| Diatonic | belonging to the key's scale |
| Dominant | scale degree 5; the V chord's function (tension → tonic) |
| Enharmonic | same pitch, different name (C# = Db) [fundamentals] |
| Extension | 9th, 11th, 13th added to a 7th chord [chords §3] |
| Figured bass | numbers showing intervals above the bass (6, 6/4, 6/5, 4/3, 4/2) [chords §5] |
| Guide tones | the 3rd and 7th of a chord [jazz §1] |
| Harmonic rhythm | how often chords change [harmony §9] |
| Hemiola | 3 against 2 at the bar level [rhythm] |
| Hypermeter | groups of bars felt as strong/weak (4-bar groups) [rhythm] |
| Inversion | a chord with a note other than the root in the bass [chords §5] |
| Leading tone | the 7th degree, a half step below the tonic; resolves up |
| Modulation | changing key [harmony §7] |
| Motif | the smallest recognisable melodic/rhythmic idea [melody] |
| Neapolitan | bII, usually in first inversion [harmony §6] |
| Neo-Riemannian (P, L, R) | chord transformations moving one or two notes [harmony §6] |
| Non-chord tone | passing, neighbour, suspension, appoggiatura, anticipation… [harmony §5] |
| Ostinato | a repeated pattern (riff, loop) [voice-leading §7] |
| Parallel 5ths/8ves | voices moving in perfect intervals; avoided in common practice [voice-leading] |
| Pedal point | a held note (often the bass) under changing harmony [harmony §5] |
| Period / sentence | standard 8-bar phrase structures [form] |
| Picardy third | a major tonic ending a minor piece [harmony §6] |
| Planing | moving a chord shape in parallel [harmony §8] |
| Predominant / subdominant | function that prepares the dominant (IV, ii) [harmony §1] |
| Relative / parallel key | same notes (C major/A minor) / same tonic (C major/C minor) |
| Secondary dominant | V of a chord other than I (V/V) [harmony §6] |
| Sequence | a pattern repeated at another pitch level [harmony §4] |
| Suspension | a held-over note resolving down by step (4-3, 7-6, 9-8) [harmony §5] |
| Syncopation | accents on weak beats or off-beats [rhythm] |
| Tendency tone | a note that must resolve (leading tone, chordal 7th) [voice-leading] |
| Tonic | scale degree 1; home |
| Tritone substitution | replacing V7 with the dominant a tritone away [jazz §3] |
| Upper structure | a triad over a dominant shell [chords §4] |
| Voice leading | how individual voices move between chords [voice-leading] |

## Indian (Hindustani) terms [indian-classical-ragas]
| Term | Meaning |
|---|---|
| Sa Re Ga Ma Pa Dha Ni | the seven swaras (sargam) |
| Komal / shuddha / tivra | flat / natural / sharp (tivra only for Ma) |
| Saptak (mandra/madhya/taar) | octave (low/middle/high) |
| Thaat | one of 10 parent scales (Bhatkhande) |
| Raga | a melodic framework: notes + movement rules + mood |
| Aroh / avroh | ascent / descent |
| Vadi / samvadi | the most / second most important note |
| Pakad / chalan | the identifying phrase / typical movement |
| Varjit | omitted note |
| Jati (audav/shadav/sampurna) | 5/6/7-note |
| Samay / prahar | time of day for a raga |
| Rasa | emotion |
| Meend / kan / andolan / gamak / murki | glide / grace note / slow oscillation / heavy oscillation / quick turn |
| Alap / jor / jhala | unmetred intro / pulsed / fast climax |
| Bandish / sthayi / antara | composition / refrain / higher verse |
| Tala / matra / sam / khali / theka | rhythm cycle / beat / beat 1 / the "empty" section / the basic tabla pattern |
| Laya (vilambit/madhya/drut) | tempo (slow/medium/fast) |
| Tihai | a phrase played 3 times landing on sam |
| Tanpura | the drone instrument (Sa–Pa) |
| Melakarta | Carnatic parent scale (72) |

## Producer terms
| Term | Meaning |
|---|---|
| 808 | a tuned sub-bass/kick sound (from the Roland TR-808) [timbre §4] |
| Half-time | the snare once per bar (beat 3): feels half the tempo [rhythm] |
| Roll / ratchet | fast repeated hats or snares (1/32, triplets) [rhythm] |
| Slide / glide / portamento | a pitch glide between notes [melody, timbre] |
| Sidechain | one sound ducking another (kick ducks the 808/pads) [timbre §5] |
| Stem | a separated part (vocals, drums, bass, other) |
| Type beat | an instrumental in the style of an artist ("Future type beat") |
| Tag | the producer's audio signature (voice drop) at the start |
| Drop | the high-energy section after a build |
| Pocket | where the groove sits in time (early/late) [rhythm] |
| Swing | delaying every second subdivision [rhythm] |
| Chop | a short cut of a sample, re-sequenced |
| Loop | a repeating 1-8 bar section |
