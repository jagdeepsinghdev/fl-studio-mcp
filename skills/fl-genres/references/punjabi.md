# Punjabi / bhangra in FL Studio

**One call:** `fl_genre("load", genre="punjabi")` (pack `fl-studio-mcp/presets/genres/punjabi.json`).
**Tempo:** about 96 BPM, light swing (0.12). Beat: the existing `presets/beats/punjabi-banger.json`
(kick 1, 5, 8, 9, 13, 15; snare on 2 and 4; claps around them; near-continuous hats). For dhol, add a
Sampler channel named "Dhol" and a `dhol` part in a beat preset (CLAUDE.md §2.3).

**Key/scale:** minor keys; pack default A minor, i - VII - VI - VII (half-bar chords), bass on the roots.
Hooks often sit in a raga-like minor; see `music-theory` -> `references/indian-classical-ragas.md`.

Convention, not auditioned - tune by ear.
