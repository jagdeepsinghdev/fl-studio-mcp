# Security policy

This server runs on your own machine and controls FL Studio through local MIDI ports and,
on macOS, the Accessibility / Screen Recording APIs. It opens **no network port**.

If you find a vulnerability (for example a tool that writes outside its work directory, or
runs a command it should not), please report it privately through
**GitHub → Security → Report a vulnerability** on this repository instead of a public issue.
You will get a first reply within a few days.

Supported: the latest release.
